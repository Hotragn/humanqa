# Short demo-video scripts

All recordings use only the local Northstar fixture. Blur or remove usernames and absolute paths. Show real commands and outputs; do not accelerate the footage in a way that implies a performance benchmark.

## 1 — 45 seconds: evidence chain

**0–5s:** Title card: “A passing feeling is not release evidence.”  
**5–12s:** Show the broken fixture's Create project page.  
**12–20s:** Run the declared journey command with safe mode visible.  
**20–32s:** Open the HTML report and expand missing success feedback, unlabeled field, keyboard blockage, and failed request.  
**32–40s:** Open the trace link and generated test.  
**40–45s:** End card: “One declared journey. Evidence, decision, regression scaffold.”

## 2 — 30 seconds: no-model proof

**0–6s:** Show an empty environment variable search and text: “No model key.”  
**6–14s:** Run HumanQA against the fixture.  
**14–24s:** Highlight raw network, axe, selector, and keyboard evidence in report JSON.  
**24–30s:** End card: “Deterministic first. Optional enrichment stays optional.”

## 3 — 35 seconds: keyboard path

**0–8s:** Tab through the broken project form until focus repeats on Keyboard checkpoint.  
**8–17s:** Show the keyboard evidence sequence and `targetReached: false`.  
**17–27s:** Restart fixed mode and rerun the same declared target.  
**27–35s:** Show the limitation: “Bounded automation does not prove complete accessibility. Manual review required.”

## 4 — 40 seconds: issue to regression

**0–10s:** Open the unlabeled project slug finding and its DOM selector evidence.  
**10–18s:** Run `humanqa generate-test report.json --finding <id>`.  
**18–30s:** Show the complete Playwright scaffold, finding ID, accessible-name assertion, and human-review selector comment.  
**30–40s:** Run against broken then fixed fixture. End: “Generated only when evidence is sufficient.”

## 5 — 30 seconds: safe refusal

**0–7s:** Open Settings and show the Delete workspace control.  
**7–15s:** Show HumanQA inspecting the safeguard without clicking.  
**15–23s:** Highlight the advisory finding and safe-mode boundary.  
**23–30s:** End card: “Automation can produce evidence without producing harm.”

## 6 — 45 seconds: pack contribution

**0–8s:** Copy the keyboard-only persona pack and edit name, goals, and evidence focus.  
**8–18s:** Run `humanqa validate-pack`.  
**18–28s:** Intentionally add a risky journey click and show validation fail.  
**28–38s:** Remove it and show pack tests pass.  
**38–45s:** Open report attribution. End: “Contribute quality context without changing TypeScript.”
