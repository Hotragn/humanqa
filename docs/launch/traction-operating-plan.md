# Traction operating plan

## Honest baseline — 2026-08-21

- GitHub stars: 0.
- GitHub forks: 0.
- GitHub traffic API: 49 unique clone events and 2 unique repository views in the available window.
- User-authored issues or Discussions: 0.
- Verified independent first audits: 0.
- Verified returning users: 0.

Clone traffic can include CI, package automation, maintainers, and bots. It is not counted as adoption. The launch problem is therefore onboarding and qualified conversation, not raw reach.

## North-star event

A qualified user runs one authorized audit on a real local or staging journey, opens at least one evidence artifact, and chooses whether to keep a report, contract, or generated test. Stars are a secondary signal.

## Four-week loop

| Week | Action                                                                          | Target evidence                                         | Decision                                   |
| ---- | ------------------------------------------------------------------------------- | ------------------------------------------------------- | ------------------------------------------ |
| 1    | Recruit three observed sessions from QA, engineering, and accessibility circles | Setup blockers and trust language                       | Fix only repeatable blockers               |
| 2    | Publish the 60-second broken/fixed fixture demo and invite one journey          | First independent audit and report comprehension        | Continue or narrow onboarding              |
| 3    | Share an architecture/security write-up and two scoped contributor issues       | Technical feedback and one outside contribution attempt | Improve contributor path only if attempted |
| 4    | Review ten-session thresholds or the actual smaller sample                      | Artifact adoption, disputed findings, return intent     | Continue, narrow, pivot, or stop           |

## Outreach rules

1. Personalize each invitation around a real QA or release workflow.
2. Ask for critical feedback, never a star, testimonial, or reciprocal promotion.
3. Do not post the same copy across communities.
4. Respect each community's self-promotion and disclosure rules.
5. Link to a reproducible demo or issue, not only the homepage.
6. Record source, response, completed audit, and adopted artifact; do not collect private target data.

## Funnel

Track only consented or platform-visible aggregates:

`qualified invitation → repository/docs visit → install attempt → browser ready → first report → evidence opened → artifact kept → second run`

The immediate target is three independent completed audits, not a star count. After those sessions, update the README language with the words users actually use and publish an anonymized failure-inclusive learning note.
