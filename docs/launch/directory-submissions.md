# Repository directory submission checklist

## Reusable factual description

HumanQA is an Apache-2.0 local CLI that runs declared Playwright journeys, collects browser and axe evidence, produces deterministic product-quality findings and transparent release decisions, and generates safe regression-test scaffolds. It requires no model API key and uploads no artifact by default.

## Before any submission

- Confirm the directory permits open-source developer tools and self-submission.
- Read current category, link, image, disclosure, and update rules.
- Use only fixture screenshots.
- Link to the repository and a versioned release, not an unreviewed hosted demo.
- State Node, pnpm, Chromium, and declared-journey requirements.
- Include explicit accessibility and redaction limitations.
- Remove empty badges and claims not supported by public evidence.
- Record submission date, copy, owner, status, and next review.

## Candidate directories and communities

Evaluate current eligibility before submitting; inclusion is not assumed:

- GitHub Topics and repository social preview.
- npm package metadata.
- Awesome Playwright, testing, accessibility, developer-tools, and AI-agent lists that accept relevant pull requests.
- Open-source launch communities and newsletters.
- Product Hunt after five independent audits succeed.
- Hacker News “Show HN” when the demo and technical explanation stand on their own.
- Relevant Reddit, Discord, Slack, and forum communities only where self-promotion rules permit it.
