# GitHub Discussions recommendations

Create these categories when Discussions is enabled:

1. **Announcements** — maintainer-only releases and research decisions.
2. **Q&A** — setup, schemas, and evidence interpretation; answers can be marked.
3. **Product feedback** — observed workflows, trust concerns, and repeated jobs.
4. **Show and tell** — sanitized fixture reports, packs, skills, and integrations.
5. **Pack ideas** — persona, journey, heuristic, framework, and industry proposals.
6. **Research and benchmarks** — method-first validation and reproducible benchmark designs.

Pin a “What did you try?” discussion asking for role, authorized environment type, command, expected outcome, observed outcome, evidence trusted, evidence disputed, next action, and whether sanitized artifacts may be shared. Remind participants not to upload private URLs, customer data, credentials, PRDs, DOM, traces, or screenshots.
