# Contributors

HumanQA is built by its contributors. No external contributor list or adoption claim is fabricated before the first merged community contribution.

## How recognition works

- Pack authors appear in pack metadata and generated report attribution.
- Code, documentation, design, research, and accessibility contributions are credited in release notes.
- First merged contributions may add the contributor's preferred name and profile link below through the same pull request.
- Significant recurring stewardship is recognized in the maintainer guide and governance records.

## Contributor list

The list will be populated from merged contributions with each contributor's consent. Git history remains the authoritative technical record.
